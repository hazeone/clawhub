# 每日晨会纪要 (Daily Morning Brief)

## 何时触发

- **自动触发**：工作日（遵循 A 股交易日历）早 7:30 自动执行
- **手动触发**：用户要求生成晨会纪要、盘前报告、今日市场概览

触发关键词：晨会, 早报, 盘前, 晨会纪要, morning brief, 今日市场。

## 执行步骤

1. 获取前一交易日所有市场指数收盘数据
2. 读取用户持仓配置，计算持仓影响
3. 检查宏观经济日历，获取已发布和待发布数据
4. 抓取持仓相关公告（交易所公告接口）
5. 计算风格/行业动量指标
6. 组装报告，按上述格式输出
7. 如配置了分发渠道，推送到企业微信/邮件

## 配置参数

用户可自定义以下参数：

```yaml
morning_brief:
  portfolio_source: "portfolio.csv"    # 持仓文件路径
  markets: [cn-a, hk, us]             # 关注的市场
  benchmark: "000300.SH"              # 业绩基准
  sectors_top_n: 5                    # 行业归因展示数量
  holdings_top_n: 5                   # 涨跌幅展示数量
  macro_calendar: true                # 是否包含宏观日历
  style_momentum: true                # 是否包含风格动量
  language: zh-CN
  distribution:
    wechat_work: false
    email: false
```

## 边界条件

- 非交易日不生成（节假日、周末）
- 持仓配置缺失时仅生成市场概览部分
- 数据源不可用时标注"数据暂缺"并继续生成其他部分
- 美股数据取最近一个交易日收盘（考虑时差和休市日差异）
