# DCF 估值模型 — A 股适配

## 何时触发

当用户需要对 A 股或港股公司进行现金流折现估值时自动激活。

触发关键词：DCF, 现金流折现, FCFF, FCFE, 估值, 内在价值, WACC,
折现率, 永续增长, 合理估值, 目标价。

## 模型框架

### 方法选择

| 方法 | 适用 | 现金流定义 |
|------|------|-----------|
| **FCFF (企业自由现金流)** | 有息负债较多的公司 | EBIT(1-t) + D&A - CapEx - ΔWC |
| **FCFE (股权自由现金流)** | 轻资产、低负债公司 | 净利润 + D&A - CapEx - ΔWC + Δ借款 |

默认推荐 **FCFF → 减去净债务 → 股权价值**，适用性更广。

### 阶段模型

| 模型 | 适用 | 说明 |
|------|------|------|
| 两阶段 | 稳定增长公司 | 高增长期 (5Y) + 永续期 |
| 三阶段 | 高速成长公司 | 高增长 (3Y) + 过渡 (3Y) + 永续期 |

## WACC 参数 — A 股适配

### 无风险利率 (Rf)

**使用中债国债到期收益率 10Y**

| 数据源 | Wind 代码 | 当前值参考 |
|--------|----------|-----------|
| 中债国债10Y | M0325689 | ~2.3% |

### 股权风险溢价 (ERP)

A 股历史 ERP 参考区间：

| 方法 | ERP | 说明 |
|------|-----|------|
| 历史法 (2005-2025) | 6.0-7.5% | 沪深300 vs 国债10Y |
| 隐含法 (当前) | 5.5-8.0% | 1/PE - Rf，动态变化 |
| **推荐默认值** | **6.5%** | 取历史法中位数 |

### Beta

```
β = Cov(Ri, Rm) / Var(Rm)
```

- 推荐使用 **周频收益率、过去 2 年**数据计算
- 基准指数：沪深300（大盘股）或中证500（中小盘）
- 进行 Blume 调整：`β_adj = 0.67 × β_raw + 0.33 × 1.0`

### Ke (股权成本)

```
Ke = Rf + β × ERP + Size Premium
```

| 市值区间 | 规模溢价 |
|---------|---------|
| > 500 亿 | 0% |
| 100-500 亿 | 1.0% |
| 30-100 亿 | 2.0% |
| < 30 亿 | 3.0% |

### Kd (债务成本)

```
Kd = 贷款加权平均利率 × (1 - 所得税率)
```

- 可从 Wind 获取公司实际借款利率
- 无数据时使用 LPR + 信用利差估算
- 所得税率默认 25%（高新技术企业 15%）

### WACC

```
WACC = Ke × (E/(D+E)) + Kd × (D/(D+E))
```

- D/E 使用目标资本结构（参考行业中位数）
- 不建议使用当前账面 D/E（可能非最优）

## 永续增长率 (g)

| 参数 | 建议范围 | 说明 |
|------|---------|------|
| 名义 GDP 增长率 | 4-5% | 中国长期名义 GDP |
| 保守估计 | 2-3% | 低于 GDP 增长 |
| **推荐默认值** | **3%** | 略低于长期名义 GDP |

硬约束：`g < WACC`，否则模型无意义。

## 执行步骤

1. **获取财务数据**
   - 近 5 年利润表、资产负债表、现金流量表
   - 计算历史 FCFF/FCFE

2. **估算预测期参数**
   - 收入增长率（参考卖方一致预期或自行建模）
   - 利润率趋势
   - CapEx/收入比
   - 运营资本变动率

3. **计算 WACC**
   - 取当日 Rf, 计算 Beta, 确定 ERP, 得到 Ke
   - 估算 Kd, 确定目标资本结构
   - 加权平均

4. **折现计算**
   ```
   Enterprise Value = Σ(FCFFt / (1+WACC)^t) + TV / (1+WACC)^n
   TV = FCFFn × (1+g) / (WACC - g)
   ```

5. **得到股权价值**
   ```
   Equity Value = EV - Net Debt + 少数股东权益调整
   Per Share Value = Equity Value / 总股本
   ```

6. **敏感性分析**
   - WACC ± 0.5% × 永续增长率 ± 0.5% 的矩阵
   - 输出敏感性表格

## 注意事项

- DCF 对假设高度敏感，**永续增长率变动 0.5% 可改变估值 20%+**
- A 股周期性行业（钢铁、化工）不适用标准 DCF，建议用 PB-ROE 或重置成本法
- 金融行业（银行、保险、券商）不使用 FCFF/FCFE，应使用 DDM 或剩余收益模型
- 始终输出敏感性分析，让用户理解估值的不确定性范围
